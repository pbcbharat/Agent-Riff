# Contributing

Thanks for helping Agent Riff become a better place for people and agents to make music together.

## Development

1. Use Node.js 20 or newer.
2. Create a focused branch.
3. Run `npm run check` before opening a pull request.
4. Describe both the human experience and the agent-tool behavior affected by the change.

Keep tool names stable, schemas bounded, interface text concise, and comments suitable for a public repository. Do not commit secrets, generated `dist/` output, copyrighted music, or user data.

## Pull requests

A good pull request includes:

- the problem and intended experience;
- screenshots or a short recording for visual changes;
- tests for validation or WebMCP contract changes; and
- accessibility notes for new interactions.
